# Revisión del apartado 4.1 (2026)

Calidad pide dejar en el 4.1 de la memoria lo que se imparte y declaran las guías docentes: contenidos, horas de actividades formativas y sistema de evaluación.

## Documentos

- [Cambios de contenidos](cambios_contenidos.md): memoria vigente frente a propuesta, con justificación.
- [Cambios de horas](cambios_horas.md): guías frente al 4.1, por materia.
- Sistema de evaluación: en curso.

## Decisiones

| Tema | Decisión |
|---|---|
| Fuentes | La memoria vigente es lo declarado; el Excel del grado (`gII2025.xlsx`), lo que se propone; las guías, lo que se imparte con el plan vigente. |
| Plan vigente frente a modificado | Solo cambia una asignatura: sale Inglés II y entra Arquitectura del software. |
| Contenidos | Prevalece el Excel. Redes de ordenadores toma el temario acordado con el profesorado. |
| Horas de una materia | Suma de las horas de sus asignaturas, actividad por actividad, según sus guías. |
| Arquitectura del software | Sin guía: se toma la distribución de Ingeniería del software II. |
| Redondeo | Cada cifra de las guías se lleva al múltiplo de 0,25 h más cercano. En la memoria se escribe el valor exacto, con hasta dos decimales, para que cada ficha sume créditos × 25. |
| Guías que se apartan de su materia | Se corrigen igualándolas con las demás guías de la materia; la memoria no cambia. |
| Prácticas y TFG | La ficha ya recoge el plan modificado; no se ajusta a las guías vigentes. |
| Evaluación | Cada materia fija una horquilla para la evaluación continua y otra para la final; la suma de los instrumentos de cada bloque de la guía debe caer dentro. |
